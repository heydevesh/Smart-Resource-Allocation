# Rule: Strict No Emojis Policy

NEVER use emojis in any project under any circumstance.
- No emojis in source code, comments, or UI templates.
- No emojis in git commit messages or PR titles.
- No emojis in markdown documentation (README, AGENTS.md, DESIGN.md, etc.).
- No emojis in conversational responses, summaries, or assistant outputs.
